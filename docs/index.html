Strip Themes & Real-World EFPS Design

Modeled after Electronic Flight Progress Strip towers (NATS EFPS, Eurocontrol) while using only Airside's official read-only HTTP API.

EFPS Paper vs Neutral Theme

Toggle EFPS Paper in the top bar: departures tint sky-blue/cyan while arrivals tint warm buff/cream, or switch off for crisp neutral slate strips.

Bottom-Up Runway Stacking

With Bottom-Up RWY enabled, HP, SEQ, and FINAL strips stack upward toward the runway bar just like real tower bays.

Runway Occupancy Alert (OCC)

The SEQUENCE RWY header switches between green CLEAR and flashing red OCCUPIED whenever traffic is lining up, rolling, or landed.

8 Position Presets + Layout Editor

Switch between 8 built-in presets or customize 1–5 columns, combine stages, hide bays, and use {RWY}, {RWY1}, and {RWY2} titles.

How It Works (Official Mods for Airside API)

Zero Airside file edits, zero encrypted file reading, zero memory hooks — purely Airside's official read-only HTTP API.

01 · Airside Mods API

GET /traffic (1 Hz)

Airside exposes live traffic, ATIS, weather, calling queues, and desk selection on 127.0.0.1:24774/traffic.

02 · TrafficClient (.NET 10)

Read-Only Polling

Lightweight HttpClient reads JSON snapshots cleanly and ignores unknown future fields.

03 · Embedded Kestrel

Local + LAN Server

Serves the strip UI and /api/traffic on port 24775 with optional LAN binding and Streamer Mode.

04 · WPF + WebView2

Resizable & Transparent

Resizable native window with Opacity slider (35%–100%), Pin Top, 1-Row Bar dock, and OBS Browser Source.

Requirements & Quick Start

1. Enable Mods for Airside

In Airside: Settings → Mods for Airside → On → Turn on → Save. Works with Airside 0.8.0.6+ and lights up all strip fields on 0.8.0.9+.

2. Run Flight Strips

Download Standalone (no .NET install needed) and run FlightStrips.exe, or build from source with .NET 10 SDK.

git clone https://github.com/rostykk/flight-strips.git
cd flight-strips
dotnet build FlightStrips.csproj -c Release
start.bat
